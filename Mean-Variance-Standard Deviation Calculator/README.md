# Mean-Variance-Standard Deviation Calculator 📊

A Python project that calculates statistical values from a **3x3 matrix** using the NumPy library.

This project is part of the **Data Analysis with Python Certification from freeCodeCamp**.

---

## 📌 Project Overview

The goal of this project is to create a statistical calculator that takes a list containing **9 numerical values**, converts it into a **3x3 NumPy array**, and calculates different statistical measurements.

The calculator returns:

- Mean
- Variance
- Standard Deviation
- Maximum Value
- Minimum Value
- Sum

The calculations are performed for:

- Rows
- Columns
- Flattened Matrix

## ⚙️ How It Works

The program receives 9 numbers as input.

Example:

```python
[0,1,2,3,4,5,6,7,8]
```

The values are converted into a 3x3 matrix:

```python
[
 [0,1,2],
 [3,4,5],
 [6,7,8]
]
```

Then NumPy is used to calculate:

- Mean
- Variance
- Standard Deviation
- Maximum
- Minimum
- Sum

The calculations are returned in a structured dictionary format.
