# 📂 Projects

## 1. Mean-Variance-Standard Deviation Calculator

📁 [View Project] Mean-Variance-Standard Deviation Calculator

### Overview

A statistical calculator built using **NumPy**.

The project takes a 3x3 matrix and calculates:

- Mean
- Variance
- Standard Deviation
- Maximum
- Minimum
- Sum

Calculations are performed for:

- Rows
- Columns
- Flattened matrix

### Main Libraries

- Python
- NumPy

## 2. Demographic Data Analyzer

📁 [View Project](./Demographic-Data-Analyzer)

### Overview

A data analysis project that explores demographic information from the **1994 Census Income Dataset** using **Pandas**.

The analysis answers questions such as:

- Race distribution
- Average age
- Education level analysis
- Salary relationships
- Countries with highest income percentage
- Occupations with high income

## 5. Sea Level Predictor

📁 [View Project](./Sea-Level-Predictor)

**2050**
