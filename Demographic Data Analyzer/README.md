# Demographic Data Analyzer 📊

A Python data analysis project that explores demographic information from the **1994 Census Income Dataset** using the Pandas library.

This project is part of the **Data Analysis with Python Certification from freeCodeCamp**.

---

## 📌 Project Overview

The goal of this project is to analyze demographic data extracted from the **1994 Census database** and answer different business and statistical questions using Python and Pandas.

The analysis focuses on understanding relationships between:

- Age
- Education Level
- Occupation
- Race
- Gender
- Working Hours
- Salary

---

## 📊 Analysis Performed

The project answers questions such as:

- How many people belong to each race category?
- What is the average age of men?
- What percentage of people have a Bachelor's degree?
- What percentage of people with advanced education earn more than $50K?
- What percentage of people without advanced education earn more than $50K?
- Which country has the highest percentage of people earning more than $50K?
- What is the most common occupation for high-income earners in India?
